# Pito: варианты расстановки коллекции

Дата: 2026-09-24.

Только визуальные концепты; это размещение не внедрено в приложение. Созданы встроенным image_gen, без CLI. Исходный размер генератора сохранён. Картинки представляют композицию, не пиксель-точную спецификацию UI.

- rock-platforms-a.png: пять каменных выступов по краям; стаканчик и гитара внизу.
- rock-platforms-b.png: три выступа и небольшие группы предметов на земле.

В обоих вариантах все 11 предметов, гитара позади какашек, свободный центр для Пито. Исходные предметные PNG и их промпты: ../assets/items-v14/ и ../assets-v14.json. Предыдущие функциональные изменения веб-прототипа прошли 384 автоматических теста; это не заменяет пользовательский тест этих двух новых композиций.
