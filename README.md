# Пито-Пито

**Твой финансовый дружище.**

Пито-Пито — игра с виртуальным питомцем для детей 7–11 лет. Игрок заботится о Пито, получает игровые деньги, планирует расходы, покупает вещи и копит на мечту. Питомец растёт по мере прохождения игровых циклов и выполнения финансовых задач.

В игре можно:

- выбрать имя, цвет и причёску питомца;
- кормить, гладить и мыть Пито;
- распределять деньги между уходом, хотелками и накоплениями;
- выполнять задания и сравнивать запланированные расходы с фактическими;
- собирать предметы, выбирать финансовую цель и пользоваться учебным вкладом;
- просматривать пройденные темы и прогресс в разделе для взрослого.

Используется только условная игровая валюта. Регистрации, рекламы и реальных платежей нет. Прогресс сохраняется на устройстве.

## Технологии

Веб-версия написана на JavaScript (ES-модули), HTML и CSS без UI-фреймворка. Node.js используется для локального сервера и подготовки ресурсов.

Android-приложение использует ту же игру внутри WebView. Код, изображения и шрифты включены в APK, поэтому подключение к Интернету во время игры не требуется. Поддерживается Android 8.0 и новее с обновлённым Android System WebView. Интерфейс рассчитан на портретную ориентацию.

## Запуск веб-версии

Требуется **Node.js 22 или новее**.

Скачайте или клонируйте репозиторий, откройте терминал в его корне и выполните:

```sh
node server.mjs
```

Откройте [http://127.0.0.1:4174/](http://127.0.0.1:4174/). Установка npm-зависимостей не нужна. Для остановки сервера нажмите `Ctrl+C`.

`index.html` нужно открывать через сервер, а не как локальный файл. Сохранения привязаны к браузеру и адресу приложения; с Android-версией они не синхронизируются.

## Структура проекта

| Файл или каталог | Назначение |
|---|---|
| `index.html` | Стартовая HTML-страница |
| `src/app.mjs` | Обработка действий и сохранение профиля |
| `src/engine.mjs` | Игровое время, потребности, деньги и рост питомца |
| `src/budget.mjs`, `src/play-plan.mjs` | Планирование бюджета и распределение денег |
| `src/missions.mjs`, `src/item-catalog.mjs` | Задания, товары, цели и цены |
| Остальные модули `src/` | Экраны, персонаж, жесты и размещение предметов |
| `styles/` | CSS интерфейса |
| `assets/` | Изображения и локальные шрифты |
| `server.mjs` | Локальный веб-сервер |
| `scripts/` | Подготовка веб-сборки и ключа подписи |
| `android/` | Android-оболочка и настройки Gradle |
| `docs/` | Описание архитектуры и инструкция сборки Android |

## Демонстрационный режим

Для отдельного демонстрационного сохранения откройте `http://127.0.0.1:4174/?qa=demo`. Удержание в правом верхнем углу в течение 1,2 секунды открывает меню с ускорением времени и сбросом профиля.

## Сборка

Подготовить автономные веб-ресурсы:

```sh
node scripts/build-web.mjs
```

Результат появится в `dist/`. Этот каталог можно разместить на статическом веб-сервере; он же используется при сборке APK.
