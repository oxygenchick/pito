# Пито-Пито

«Твой финансовый дружище». Офлайн-тамагочи для детей 7–11 лет: уход за питомцем, планирование карманных денег, покупки и накопление на мечту. Все деньги условные; рекламы, платежей и регистрации нет.

**Активный проект теперь здесь, в `pito`.** 24.09.2026 сюда скопировано содержимое `web-prototype`, без вложенной папки. Исходная `web-prototype` сохранена как предыдущая версия и больше не является рабочей. История `.git` сохранена. Уже существовавшие удаления Unity-файлов не отменялись. Коммит и отправка на сервер автоматически не выполняются.

## Быстрый запуск

Нужен Node.js 22 или новее. Устанавливать npm-зависимости для игры не требуется.

```sh
node server.mjs
```

Открыть **http://127.0.0.1:4174/**. Порт 4174 выбран, чтобы не останавливать старую версию на 4173. Можно задать переменную окружения `PORT`. Сервер слушает только этот компьютер.

```sh
node --test
node scripts/build-web.mjs
```

Вторая команда собирает автономный каталог `dist/`. В APK входят именно эти ресурсы, а не ссылка на сайт. Нельзя запускать ES-модули двойным кликом по `index.html`: используйте HTTP-сервер или APK.

**Сохранения браузера и Android независимы.** Смена порта также меняет хранилище браузера: старый профиль на 4173 не удалён, но на 4174 будет новый. Для отдельного тестового профиля добавьте `?qa=demo`. Не используйте сброс на пользовательском сохранении.

## Android

- Android 8.0+ (minSdk 26), compile/target SDK 35.
- Java 17, Gradle Wrapper 8.11.1, Android Gradle Plugin 8.9.1.
- Java WebView + AndroidX WebKit 1.12.1; локальные ресурсы через HTTPS-подобный адрес WebViewAssetLoader. Настоящий сервер и Интернет не нужны.
- Пакет `ru.pitopito.hackathon2026`, версия `0.1.0`, код версии `1`. Наличие этого имени в RuStore ещё не проверялось.
- Портретный экран. Требуется обновлённый Android System WebView: текущий CSS использует контейнерные единицы/запросы.
- Инструкция: [сборка и установка APK](docs/ANDROID.md).

## Что реализовано

Создание питомца (3 цвета × 3 причёски), сохранение, 3 стадии роста, ласка/еда/мытьё, загрязнение и уборка, задания с наградами, кошелёк и журнал операций, план по 3 категориям, сравнение с фактом, 6 обычных вещей и 5 целей, копилка, учебный вклад, раздел взрослого, справка, скрытые инструменты тестирования. Главная показывает текущую локацию с питомцем, покупками и грязью без игрового HUD. У каждого предмета фиксированное место на каменных выступах или земле.

Технически рабочая механика не означает полного соответствия конкурсу: открытые вопросы перечислены в [матрице ТЗ](docs/REQUIREMENTS.md). В частности, вводный платный уход идёт **до первого плана** по выбранному UX; это расходится с формулировкой ТЗ/Q&A о плане до расходов и требует отдельного решения перед сдачей.

## Git и ключ подписи

Коммитить исходники, тесты, ресурсы, документацию, Gradle Wrapper. Не коммитить SDK, `dist/`, `builds/`, кеши, `local.properties`, `.signing/` и APK. APK передавать отдельным файлом или вложением релиза.

**Сделайте приватную резервную копию `.signing/`.** Эта папка содержит ключ и пароль для обновления установленного приложения. При потере ключа нельзя выпустить совместимое обновление с той же подписью. Файл пароля нельзя публиковать в репозитории или документации.

Сброс тестового профиля: удерживать невидимую область в правом верхнем углу 1,2 секунды, открыть инструменты разработчика. Для пользовательских данных есть подтверждаемый сброс в разделе взрослого. На Android удаление данных приложения через настройки ОС также стирает профиль.
