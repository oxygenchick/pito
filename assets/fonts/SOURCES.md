# Balsamiq Sans

Original, unmodified TTF files downloaded from the official Google Fonts repository on 2026-09-24.

- Regular, weight 400: https://raw.githubusercontent.com/google/fonts/main/ofl/balsamiqsans/BalsamiqSans-Regular.ttf
- Bold, weight 700: https://raw.githubusercontent.com/google/fonts/main/ofl/balsamiqsans/BalsamiqSans-Bold.ttf
