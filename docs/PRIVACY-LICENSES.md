# Данные и сторонние ресурсы

## Данные

Только локальный игровой профиль: вымышленное имя, внешность, прогресс, игровые деньги/операции, задания и настройки. Не запрашиваются ФИО, возраст, контакты, реальный бюджет, банковские данные. Нет сервера, рекламы, аналитики и телеметрии. APK не запрашивает аппаратные или сетевые разрешения. Резервное копирование Android отключено.

Удаление: подтверждённый сброс в разделе взрослого или удаление данных/приложения через Android. Скрытое меню разработчика предназначено для демонстрационного профиля, не для обхода приватности. Локальное хранилище не зашифровано отдельно от системной защиты Android. Арифметический барьер защищает от случайного входа, но не является аутентификацией.

## Зависимости

- AndroidX WebKit 1.12.1 и транзитивные AndroidX: Apache License 2.0, лицензии в опубликованных артефактах Google Maven.
- Android SDK/Build Tools: лицензия Google Android SDK, инструмент сборки, не кладётся в репозиторий.
- Gradle Wrapper/Gradle: Apache License 2.0; AGP: Apache License 2.0.
- Microsoft OpenJDK 17: GPLv2 + Classpath Exception, только инструмент сборки.
- Balsamiq Sans: SIL Open Font License 1.1, текст `assets/fonts/OFL.txt`; шрифты включены локально.
- Игровой JavaScript не имеет npm runtime-зависимостей.

Иллюстрации созданы для проекта по авторским скетчам с использованием генерации изображений. Лицензия шрифта находится в `assets/fonts/OFL.txt`. Общая открытая лицензия на код и иллюстрации проекта пока не установлена; доступность репозитория сама по себе не предоставляет права на их свободное распространение.
