# Данные и ресурсы

## Что хранится

Только локальный игровой профиль: имя питомца, внешность, потребности, прогресс, игровые деньги, покупки, задания и настройки. Для имени можно использовать вымышленное слово. Реальные финансовые и контактные данные не требуются.

Аккаунтов, рекламы, аналитики и телеметрии нет. APK не запрашивает доступ к сети, камере, микрофону, контактам или геолокации. Профиль не отправляется на сервер; резервное копирование Android отключено.

## Удаление и защита

Профиль можно сбросить с подтверждением в разделе «Для взрослого» или удалить вместе с данными приложения через Android. Арифметический пример перед разделом взрослого защищает от случайного входа, но не заменяет пароль. Локальное хранилище не зашифровано отдельно от системной защиты устройства.

## Ресурсы и зависимости

- Balsamiq Sans — SIL Open Font License 1.1; [текст лицензии](../assets/fonts/OFL.txt).
- AndroidX WebKit 1.12.1 и зависимости AndroidX — Apache 2.0.
- Gradle и Android Gradle Plugin — Apache 2.0; Android SDK и JDK используются только как инструменты сборки.
- JavaScript не использует сторонние npm-библиотеки во время игры.
- Музыка и звуки синтезируются приложением.
- Иллюстрации подготовлены по скетчам команды с помощью генерации изображений OpenAI. Во время игры ИИ не используется и данные игрока ему не передаются.

Открытая лицензия на собственный код и иллюстрации команды пока не объявлена. Публичность репозитория сама по себе не предоставляет права на их свободное распространение.
