# Сборка и запуск на Android

## Требования

- Node.js 22 или новее.
- JDK 17.
- Android SDK: `platforms;android-35`, `build-tools;35.0.0`, `platform-tools`.
- Переменные окружения `JAVA_HOME` (путь к JDK) и `ANDROID_HOME` (путь к Android SDK).

SDK можно установить через Android Studio или Android SDK Command-line Tools. Перед установкой компонентов необходимо принять лицензию Android SDK.

Gradle 8.11.1 загружается через включённый в репозиторий Gradle Wrapper. Используются Android Gradle Plugin 8.9.1 и AndroidX WebKit 1.12.1. Для первой сборки нужен Интернет; для работы установленной игры — нет.

## Подготовка

Из корня репозитория выполните:

```sh
node --test
node scripts/build-web.mjs
```

В `dist/` появятся игровые ресурсы для включения в APK. Повторяйте подготовку после изменения кода, стилей или изображений.

## Отладочная сборка

Windows:

```powershell
cd android
.\gradlew.bat assembleDebug
```

macOS/Linux:

```sh
cd android
sh ./gradlew assembleDebug
```

Результат: `android/app/build/outputs/apk/debug/app-debug.apk` относительно корня репозитория. Для этой сборки собственный ключ подписи не требуется.

## Релизная сборка

При первой сборке собственной версии создайте ключ подписи из корня репозитория:

```sh
node scripts/init-signing.mjs
```

Ключ и параметры подписи сохраняются в `.signing/`. Эта папка исключена из Git. Храните её резервную копию в защищённом месте: для обновлений приложения нужен тот же ключ. Если ключ уже существует, повторно создавать его не нужно.

Затем выполните:

```powershell
cd android
.\gradlew.bat assembleRelease
```

На macOS/Linux используйте `sh ./gradlew assembleRelease`.

Результат: `android/app/build/outputs/apk/release/app-release.apk` относительно корня репозитория. Для изменения номера версии используйте `versionCode` и `versionName` в `android/app/build.gradle`.

## Установка и запуск

Скопируйте APK на телефон и откройте его. Если Android запросит разрешение на установку из выбранного источника, разрешите её для используемого файлового менеджера. После установки откройте «Пито-Пито» в списке приложений.

Альтернативный способ — через ADB с подключённым телефоном и включённой USB-отладкой. Команды выполняются из корня репозитория:

```sh
adb install -r android/app/build/outputs/apk/release/app-release.apk
adb shell am start -n ru.pitopito.hackathon2026/.MainActivity
```

Отладочная и релизная сборки используют разные подписи. Установка одной поверх другой может потребовать удаления предыдущей версии, что удалит её локальное сохранение.

## Особенности приложения

- Минимальная версия Android: 8.0 (API 26). Target SDK: 35.
- Имя пакета: `ru.pitopito.hackathon2026`.
- Нужен обновлённый Android System WebView для поддержки используемых возможностей CSS.
- Все игровые ресурсы находятся внутри APK. Сетевые и аппаратные разрешения не запрашиваются.
- Профиль хранится локально и не синхронизируется с браузером.
- При сворачивании игра сохраняет состояние и прекращает полив.

После сборки проверьте на целевом устройстве первый запуск, создание питомца, сохранение после закрытия и игру без подключения к сети.
