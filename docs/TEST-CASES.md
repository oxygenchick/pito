# Проверка приложения

Приложение проверено командой на нескольких устройствах. Автоматические проверки охватывают экономику, сохранение, задания и отображение экранов; для APK проверяется релизная подпись. Ниже — короткий список для повторной проверки после изменений.

| Сценарий | Ожидаемый результат |
|---|---|
| Создать Пито и получить стартовые деньги | Имя и внешность сохранены; 20 штучек начислены один раз |
| Купить еду и включить дождик | Деньги расходуются, потребности меняются; полив прекращается после отпускания |
| Составить план | Сумма не превышает кошелёк; деньги пока не списываются |
| Купить вещь или отложить покупку | При покупке одно списание и предмет в локации; без средств покупка недоступна |
| Пополнить копилку и купить мечту | Суммы пересчитаны; списана только цена мечты |
| Открыть вклад на 4 штучки | Сумма недоступна до срока, затем возвращается 6; повторного начисления нет |
| Завершить день с выполненным и невыполненным планом | Итог соответствует действиям; рост рассчитан по уходу, плану и накоплениям |
| Перезапустить без Интернета | Игра открывается, профиль и предметы сохранены |
| Открыть раздел для взрослого и отменить сброс | Раздел доступен после верного ответа; отмена сохраняет профиль |
| Проверить короткий и вытянутый экран, клавиатуру, звук | Кнопки доступны, содержимое прокручивается; Done закрывает ввод; звук отключается |

Сброс проверяйте только на профиле, который не нужно сохранять. Для ускорения удерживайте правый верхний угол 1,2 секунды.
