# Архитектура

[К приложению](../README.md) · [Сборка из исходников](ANDROID.md)

Пито-Пито работает целиком на устройстве. HTML, CSS и JavaScript образуют общую игру для браузера и Android. Оболочка на Java открывает её в WebView. Сервер, внешнее API и база данных не требуются.

## Структура

| Каталог или модуль | Назначение |
|---|---|
| `src/app.mjs` | Действия, навигация, сохранение |
| `src/engine.mjs` | Время, потребности, денежные операции, рост |
| `src/budget.mjs`, `src/play-plan.mjs` | План дня и распределение денег |
| `src/missions.mjs` | Задания, условия, награды и объяснения |
| `src/daily-challenges.mjs`, `src/bank-access.mjs` | Дополнительные задания и согласованный доступ ко вкладу |
| `src/parent-progress.mjs`, `src/learning-copy.mjs` | Отметки навыков и тексты для взрослого и ребёнка |
| `src/portrait-guard.mjs` | Подсказка и пауза при горизонтальном положении мобильного браузера |
| `src/item-catalog.mjs` | Вещи, мечты, цены |
| `src/views.mjs` и модули экранов | Интерфейс |
| `src/visuals.mjs` | Отображение персонажа и предметов |
| `src/audio.mjs` | Музыка и эффекты через Web Audio API |
| `src/onboarding.mjs` | Поэтапное обучение и сохранённые паузы между новыми механиками |
| `styles/`, `assets/` | Стили, изображения и локальные шрифты |
| `android/` | Android-оболочка и Gradle |
| `scripts/`, `server.mjs` | Подготовка сборки и локальный сервер |

## Как обрабатывается действие

Нажатие передаётся в `app.mjs`. Игровая логика проверяет условия и сумму, обновляет профиль и журнал операций. Интерфейс показывает результат, профиль сохраняется.

План и реальные операции разделены. Кошелёк, копилка и вклад учитываются отдельно. Итоги завершённого дня хранятся снимком и не пересчитываются после следующих покупок. [Правила экономики и роста](GUIDE.md#деньги-и-план).

При сравнении с планом накопления включают чистое пополнение копилки и новые взносы на вклад. Покупка мечты из копилки не считается новой тратой кошелька на вещи. Вводный уход, оплаченный до первого плана, исключается из расходов этого плана. Новые вклады: от 3 штучек на два игровых дня. Доход: 3–7 штучек дают +1, 8–12 дают +2, от 13 дают +3. Досрочный возврат возвращает только основную сумму и уменьшает чистые накопления дня. Старые договорённости сохраняются при загрузке.

## Интерфейс

Короткие тексты и одно основное действие в окне помогают проходить игру последовательно. Иконки дополнены подписями, цвет — числами и текстом; покупка и сброс требуют подтверждения. Потребности открываются по нажатию на Пито, чтобы не перегружать основной экран. Звук отключается в настройках. Системное уменьшение движения учитывается стилями.

## Сохранение

Профиль — JSON в `localStorage`:

- внешность: `name`, `color`, `hair`, `stage`;
- потребности: `needs.food`, `needs.clean`, `needs.affection`;
- время и рост: `cycle`, `completedCycles`, `elapsed`, `growthPoints`;
- деньги: `wallet`, `savings`, `goal`, `deposit`;
- коллекция: `owned`, `goalsWon`;
- история: `plan`, `plans`, `ledger`, `periods`, `missions`.

`engine.restore()` проверяет и восстанавливает профиль. Запись происходит после действий, периодически во время игры и при сворачивании. Облачной синхронизации нет; сохранения Android и браузера независимы.

## Android

`MainActivity.java` загружает ресурсы APK через AndroidX WebViewAssetLoader. Внешние запросы блокируются. При сворачивании общий контроллер сохраняет игру и прекращает полив. Оболочка также обрабатывает закрытие экранной клавиатуры.

`scripts/build-web.mjs` собирает файлы игры в `dist/`; Gradle включает их в APK. Документация и инструменты разработки в приложение не попадают. [Команды сборки](ANDROID.md).

## Расширение контента

Задания описаны в `MISSIONS`: тема, действие, условие `criterion`, награда и пояснение. Задание на существующем игровом событии можно добавить без изменения основной логики. Для нового типа события потребуется обработчик. После изменения каталога нужно пересобрать APK.

Товары и мечты добавляются в `item-catalog.mjs` вместе с изображением и местом в локации. ИИ во время игры не используется.

## Баланс заботы

За полный игровой день сытость уменьшается на 39,6 пункта. Яблоко стоит 2 штучки и восстанавливает 40 пунктов: ориентир для обычной игры составляет одно кормление в день. Бесплатный вводный уход не меняется.
