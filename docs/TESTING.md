## Ручной сценарий Android

1. Установить APK. В авиарежиме открыть старт; проверить загрузку графики/локального шрифта.
2. Создать профиль, кириллическое имя, по очереди проверить 3 цвета и 3 причёски.
3. Получить 20, покормить за 2; помыть, проверить списание 1 за 3 секунды, бесплатную уборку.
4. Свернуть при удержании дождя: вода должна остановиться. Вернуться, проверить баланс.
5. Подтвердить план, выбрать цель, пополнить копилку; сумма не может превысить остаток до цели.
6. Купить вещь или отложить покупку. Сравнить план/факт, пройти минимум 5 дней через debug-ускорение без накрутки результатов.
7. Проверить вклад, срок, начисление дохода и запрет досрочного снятия.
8. Проверить рост до усиков и ног, места всех 11 вещей, тап по Пито/предметам.
9. Закрыть приложение системной кнопкой, выгрузить процесс, открыть снова. Проверить имя, деньги, вещи, цель, задания.
10. Зайти через взрослый барьер, проверить отчёт; отменить сброс, убедиться, что данные не стерлись. Затем сбросить только тестовый профиль.
11. Измерить холодный старт (≤5 с), отклик (≤1 с), проверить увеличенный системный шрифт и клавиатуру.

Скрытые инструменты: удержание 1,2 секунды в правом верхнем углу. Не использовать реальный профиль для сброса/изменения баланса.
